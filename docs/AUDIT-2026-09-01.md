# تدقيق petravex — estratijiyatest.com

**التاريخ:** 2026-09-01 · **الستاك:** Next.js (App Router) + TypeScript + Tailwind، مبني بـ `output: 'export'` (static export) + next-intl · **عدد الصفحات:** 36 صفحة مبنية (18 مسار × لغتين: إنجليزي بالجذر، عربي تحت `/ar`) + صفحة 404

> ⚠️ **الاسم بيضلّل.** `estratijiyatest.com` **مش** موقع Estratijiya — هو موقع **Petravex**
> مركون على دومين تجريبي **ما بيملكه العميل**. مرجع الربط: `docs/infrastructure/INVENTORY.md`.
> كل الـ SEO والـ metadata والـ JSON-LD بهاد التقرير مبنية على براند **Petravex** والدومين
> الحقيقي **petravex.com**، مش على اسم الدومين التجريبي.

## ملخّص

الريبو كان نضيف من ناحية git (صفر تعديلات معلّقة على `8608fe6`) بس محمّل بمخلّفات ميتة:
كل عدّة الـ VPS (Docker + Traefik + سكربتات نشر) بعد ما انمسح السيرفر، ملف compose تبع
**عميل تاني** (`_tojan-compose.yml` → `rshad.net`)، نسخة عالقة من ريبو المهارات
(`estratijiya-skills/`)، وباسوورد VPS **بنص صريح** بـ `deploy.local.env`. على صعيد الـ SEO
الموقع كان شبه فاضي: الـ 36 صفحة كلها بتتشارك **نفس الـ `<title>` ونفس الـ description**،
بلا canonical، بلا `og:url`/`og:image`/`og:site_name`، بلا JSON-LD، بلا hreflang، وبلا
`robots.txt` أو `sitemap.xml` أصلاً (ولا `app/robots.ts` ولا `app/sitemap.ts` كانوا موجودين).

انشال الباسوورد وانحذفت كل المخلّفات، وانبنت طبقة SEO كاملة بالمصدر — metadata فريدة لكل
صفحة، canonical مطلق، hreflang حقيقي بـ URLs منفصلة، JSON-LD، `robots.ts` و `sitemap.ts` —
زائد هيكل Search Console و GA4 **معطّل بالكامل** لحد ما تجي المعرّفات الحقيقية. صفر تغيير
بصري: `git diff` ما فيه ولا سطر بيمسّ CSS أو layout أو نص مرئي، و `tsc --noEmit` بيعدي نظيف.

**🔴 الأهم:** الباسوورد لازم يتبدّل، وزر تبديل اللغة مكسور على كل صفحة إنجليزية.

## 🔴 حرج

### 1. باسوورد الـ VPS كان بنص صريح على القرص — **لازم يتبدّل**

`petravex/deploy.local.env` كان فيه `VPS_PASSWORD` بنص صريح، جنب `VPS_HOST`.

**شو صار:** الملف **غير متتبّع بـ git** (مستثنى من قبل بـ `.gitignore:38`)، فحسب القاعدة الحمراء
#3 **ما انحذف** — انتقل لـ `F:\coding\_archive\site-cleanup-2026-09-01\petravex\deploy.local.env`.
القيمة ما انطبعت لا بالتقرير ولا برسالة الـ commit ولا باسم ملف.

**فحص التاريخ — الخبر الحلو:** الباسوورد **ما انكمّت ولا مرة**. تحققت بطريقتين:

1. `git log --all -S'<القيمة>'` → **0 commits**.
2. مسح **كل blob** بتاريخ الريبو (`git rev-list --all --objects` → `git cat-file --batch`)
   بحثاً عن القيمة الحرفية → **0 تطابق**.

كمان `scripts/_setup-ssh-key.py` (اللي طلع بالبحث على كلمة `PASSWORD`) كان بيقرا
`os.environ["VPS_PASSWORD"]` — يعني ما كان فيه قيمة مكتوبة أبداً. مسح شجرة الشغل كلها
(بما فيها الـ 15 worktree العالقة) لقى **نسخة وحيدة** من القيمة، هي اللي انشالت.

**يعني:** ما في حاجة لـ `git filter-repo` ولا rewrite للتاريخ ولا force-push.

> 🔴 **بس الباسوورد لازم يتبدّل بغضّ النظر.** كان مكشوف على القرص بنص صريح لمدة غير معروفة،
> بمجلد بينمسح عليه backup وبينفتح على أدوات كتير. "ما انكمّت" ≠ "ما انكشف".
> والملف نفسه كان مكتوب عليه `Rotate after first successful deploy` وهاد ما صار.
> السيرفر انمسح، بس إذا نفس الباسوورد مستعمل بأي مكان تاني — بدّله هناك كمان.

### 2. زر تبديل اللغة بيولّد رابط 404 على **كل** صفحة إنجليزية

`components/nav/LocaleSwitcher.tsx` بيحسب الهدف من `usePathname()`. وقت الـ prerender المسار
الحقيقي للصفحات الإنجليزية هو `/en/careers` (لأن الـ export بيولّدهم تحت `/en/`)، بس
`swapLocale()` بيشيل بادئة اللغة **بس إذا مش اللغة الافتراضية** — والإنجليزي هو الافتراضي.
فالنتيجة بالـ HTML الستاتيكي المنشور:

- زر **EN** → `/en/careers/` — شغّال، بس بقفزة 301 عبر الـ `.htaccess`.
- زر **AR** → **`/ar/en/careers/`** — قاعدة الـ `.htaccess` بتطابق `^en/` من الجذر بس، فهاد
  المسار **404 صريح**.

الأثر عملياً: بعد ما يشتغل الـ JS بيصير `usePathname()` يقرا المسار الحقيقي من المتصفح
و React بيصلّح الـ `href`، فالمستخدم اللي عنده JS شغّال بيوصل. بس **الزواحف والقراءة قبل
الـ hydration بتشوف 404** — يعني النسخة العربية غير مكتشفة من أي صفحة إنجليزية.

**ليش ما صلّحتها:** الإصلاح (تطبيع بادئة `/en` بـ `swapLocale`) بيغيّر سلوك توجيه، وما فيني
أشغّل build ولا متصفح لأتحقق منه بهالجولة — وإصلاح غلط بيكسر زر اللغة كلياً على موقع عميل حي.
وبما إن الفهرسة مقفولة أصلاً (تحت)، الضرر الفعلي حالياً صفر والاستعجال صفر.

**الإصلاح المقترح** — بـ `swapLocale()`، شيل بادئة اللغة **دايماً** مش بس للغات غير الافتراضية،
بحيث `/en/careers` بينقرا كـ `/careers`. لازم ينتحقق بـ build + تصفّح فعلي قبل النشر.

### 3. الفهرسة لازم **تضلّ مقفولة** لحد ما ينتقل الدومين

الموقع منشور على `estratijiyatest.com` — **دومين تجريبي ما بيملكه العميل**، والنقل قرار
لسا مفتوح. فتح الفهرسة هلق بينتج محتوى مكرّر وبيحطّ الدومين الغلط جنب اسم البراند بنتائج
البحث، وبيضل مفهرس بعد النقل.

عشان هيك `app/robots.ts` عم يطلع **`Disallow: /`** عن قصد، وكل canonical و hreflang
بيشيروا لـ `petravex.com` مش للدومين التجريبي. الشغل التقني كله **جاهز** — بس مطفي.

> **يوم النقل الفعلي لـ petravex.com:** بدّل `ALLOW_INDEXING` من `false` لـ `true` بـ
> `lib/seo.ts` (سطر واحد)، ابنِ، انشر، وبعدين قدّم الـ sitemap على Search Console.

### 4. كل إصلاحات هالجولة بالمصدر — **ما بتوصل الإنتاج بلا إعادة بناء**

المنشور فعلياً هو محتوى `out/`، وهو **مخرج بناء مستثنى من git**. كل شي عملته (الـ metadata،
الـ canonical، الـ JSON-LD، `robots.txt`، `sitemap.xml`، هيكل GA4) عايش بالمصدر وبينطبع
وقت `next build` الجاي. الـ `out/` الحالي على السيرفر **ما تغيّر ولا بايت** — وهاد مقصود:
القاعدة الحمراء #2 بتمنع لمس السيرفر.

> **مطلوب من Taif:** `npm run build` + إعادة نشر `out/` قبل ما تظهر أي فايدة من هالجولة.
> وانتبه: خطوة نقل الإنجليزي من `out/en/` لجذر `out/` **يدوية وغير موثّقة بأي سكربت** —
> لازم تتعاد بعد كل build، وإلا بينكسر الموقع كله.

## ✔️ إثبات صفر تغيير بصري

1. **`git diff --cached` مقروء سطر-سطر.** فلترة الـ diff كامل على
   `className|style=|css|font|color|padding|margin|rounded|flex|grid|bg-|text-`
   رجّعت **صفر أسطر**. ولا ملف `.css` انلمس.

2. **ملفات الـ rendering اللي انلمست: اتنين بس، والتنتين إضافة فقط.**
   - `app/[locale]/page.tsx`: انضاف `<OrganizationJsonLd />` كأول ابن جوّا
     `<main className="relative">`. ترتيب `Header → Hero → DivisionsGrid → StoryTimeline
     → StatsBar → DualCTA → NewsHighlight → Footer` **ما تغيّر**.
   - `app/[locale]/(pages)/group/[division]/page.tsx`: `<PlaceholderPage>` انلفّت بـ
     Fragment (`<>`) مع `<BreadcrumbJsonLd />` قبلها. **props الـ `PlaceholderPage` نفسها
     حرفياً** (`eyebrow` / `title` / `description` بلا أي تعديل).

3. **ليش الإضافتين ما بيقدروا يحرّكوا بكسل:**
   - `<script type="application/ld+json">` عليه `display: none` من UA stylesheet،
     و Tailwind preflight ما بيلمس `script`. ما بياخد صندوق ولا مساحة.
   - الـ Fragment (`<>`) ما بيطلع عقدة DOM أصلاً.
   - فحصت `app/globals.css` و `PlaceholderPage.tsx` و `(pages)/layout.tsx` على
     `:first-child` / `:first-of-type` / `:nth-child` / `> *` / `+ *` / `~ *` / `:has()` /
     `space-y-` / `divide-` → **ولا تطابق**. يعني ما في قاعدة CSS بترتيب-حسّاسة ممكن الـ
     script يزحلقها.
   - `<GA4 />` بيرجع `null` طول ما الـ ID placeholder — صفر markup.

4. **باقي التعديلات كلها `<head>` أو برّا الـ rendering:**
   `generateMetadata` بيطعّم الـ `<head>` بس. `app/robots.ts` و `app/sitemap.ts` مسارات
   metadata بتولّد ملفات منفصلة ولا بتمسّ ولا صفحة. `lib/seo.ts` ثوابت. الباقي حذف ملفات
   ميتة (Docker/deploy/skills — ولا وحدة مستوردة من أي مكون: تحققت) وتوثيق.

5. **عنوان الرئيسية محفوظ بايت-بايت.** استعملت `title.absolute` بدل قالب `%s — Petravex`
   عشان نصّ التبويب يضل حرفياً `Petravex — An integrated building-materials group` /
   `بترافكس — مجموعة متكاملة لمواد البناء` — بلا أي تبديل.

6. **`tsc --noEmit` بيعدّي نظيف** (exit 0) بعد كل التعديلات — بلا `npm install`، بلا
   `next build`، بلا dev server، بلا متصفح، حسب قيود الجولة.

7. **بايتات الإنتاج ما تغيّرت.** `out/` مستثنى من git وما انلمس، والسيرفر ما انلمس
   (القاعدة الحمراء #2). الشكل الحالي المنشور مطابق 100% لما كان قبل التدقيق.
